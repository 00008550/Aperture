# rawsql-rules.txt — the ONE definition of "a raw-SQL entry point" and of what is exempt from it
# (CLAUDE.md invariant 2, plan 011-P7). Three detectors read this file and nothing else:
#
#   scripts/measure.sh rawsql      lists every match, production vs exempt
#   scripts/measure.sh gate        GATE 2 — every non-exempt match needs tenant_id nearby
#   RawSqlIsScopedTests            fails the build on any non-exempt match
#
# 011-F5: the three used to carry their own copies of the pattern and had drifted — an
# ExecuteSqlAsync in production code was seen by GATE 2 only. Do not copy these values anywhere;
# read this file.
#
# Format: `key=value`, one per line; `#` starts a comment line. The pattern must be valid for
# both GNU `grep -E` and .NET Regex (so: alternation, groups, `?`, `\b` — nothing engine-specific).
#
# Pattern: Dapper (any mention — `using Dapper;` is how any Dapper `.Query<` reaches a file),
# a bare NpgsqlConnection (word-bounded, so NpgsqlConnectionStringBuilder is not a connection),
# and EF Core's raw-SQL escape hatches in every sync/async/Raw/Interpolated form, including
# SqlQuery/SqlQueryRaw. A bare `.Query<`/`.QueryAsync<` is deliberately NOT an alternative: a
# Dapper one cannot compile without `using Dapper;` (matched), and every other one in src/ is a
# call on ScopedConnection — the sanctioned door itself.
pattern=\b(Dapper|NpgsqlConnection|FromSql(Raw|Interpolated)?|ExecuteSql(Raw|Interpolated)?(Async)?|SqlQuery(Raw)?)\b

# Exemptions are path rules, never magic comments — a comment a developer can paste anywhere is
# a bypass, not an exemption.
# exempt-segment: any path containing this text (test projects: fixtures and the detector's data).
exempt-segment=.Tests/
# exempt-dir: any path starting with this directory (the sanctioned ScopedConnection wrapper; it
# enforces tenant + scope structurally through RLS, proven by ScopedConnectionRlsTests).
exempt-dir=src/Aperture.SharedKernel/Data/
# exempt-file: this exact path only. DemoSeed's two ExecuteSqlAsync calls are a cluster-level
# `ALTER ROLE` setting the dev aperture_reader password (bound param + format %L/%I); they touch no
# tenant rows and the seed is unreachable outside Development. Any OTHER file under Development/
# is not exempt.
exempt-file=src/Aperture.Api/Development/DemoSeed.cs
