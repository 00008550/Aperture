### What this portion does

The cross-cutting visual foundation for the reactive console:

- **Aurora Glass token system** — `styles.css` restructured into first-class **light and dark** sets: teal + indigo accents (light `--accent:#28b6a4` / `--accent-2:#6f83f5`; dark `--accent:#41d6c3` / `--accent-2:#8a9bff`), cool-slate neutrals, and semantic good/warn/bad kept separate from the accent.
- **Type system** — Bricolage Grotesque (display), IBM Plex Sans (body), IBM Plex Mono (data/numerals) via Google Fonts with real fallback stacks.
- **Frosted-glass panels** — translucent + `backdrop-blur`, hairline border, soft shadow, ~16px radius.
- **Theme system** — new `app/theme.ts` with a user-facing toggle; the choice persists across reloads via `localStorage`, defaulting from `prefers-color-scheme`.
- **Shell layering** — new `app/Shell.tsx`; the field sits on a dedicated z-index tier behind the glass content panels.
- **Field upgrade** — `BlockField.tsx` / `fieldMath.ts` upgraded from P1 dots to the Aurora Glass form: big connected rounded glass panes with thin seams, bulging/leaning/refracting toward the cursor, a diagonal reflection streak clipped inside each pane, edge light on wake, and a click impulse ripple — still Canvas 2D + a single rAF loop. `prefers-reduced-motion: reduce` yields one static frame, no loop (`data-field-state="reduced"`); canvas-init failure degrades to `data-field-state="degraded"` with the app fully usable.

### Round-2 fix (commit 37522e9)

Round 1 found the reduced-motion field went blank on resize (the `ResizeObserver` re-sized the canvas bitmap, clearing it, with no loop to repaint). Fixed: the observer callback now does `resize(); if (reduced) draw(performance.now());` — it repaints the single static frame and never calls `schedule()`, so the reduced path stays loop-free. The degraded (`ctx===null`) path returns before the observer is created, so it cannot reach the repaint. A new `BlockField.test.tsx` case drives the observer callback by hand and asserts a repaint (`clearRect`) with `requestAnimationFrame` never called — non-tautological, since `resize()` alone never clears.
