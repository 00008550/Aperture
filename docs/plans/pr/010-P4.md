## What

Plan: `docs/plans/010-reactive-console-experience.md` P4 · Roadmap: ARCHITECTURE §13 item 010.

- Accounts grid: every `toGridModel` state (loading, error+retry, no-scope, empty, rows), keyset "load more", selection in the URL (`/accounts/:id`), plus hover/focus/selection micro-interactions. Reduced-motion disables them.
- Create (POST) and edit (PATCH with `expectedVersion`). The edit form sends the current owner unchanged. The console has no reassignment UI yet; edge 8 is a server behaviour.
- `ApiError` now keeps the response body: parsed JSON, raw text, or `null` when empty. `serverMessageOf` reads `{error}` and ProblemDetails. The one `apiAuthed` 401/403 sign-out path is unchanged.
- 409 on PATCH: the query is refetched and the draft kept. It is never resent on its own. The user must pick "Re-apply" (sent with the refetched version) or "Discard". Double-submit is blocked by `isPending` plus a single-flight ref.
- Sections not built yet have gated placeholder routes.

No .NET change and no new endpoint (invariant 5 holds).
