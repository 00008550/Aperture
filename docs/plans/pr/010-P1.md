## 010-P1 — The living field (self-contained interactive shell)

Plan: [`010-reactive-console-experience.md`](../010-reactive-console-experience.md), portion **P1**.
Roadmap: ARCHITECTURE.md §13 item 010 (Reactive console: a living Sales surface).

### What this portion does
Adds a self-contained Canvas 2D reactive block-field (`field/BlockField.tsx`) mounted **behind** the
existing session UI (both the sign-in surface and the authenticated shell), plus the pure motion
module it wires up (`field/fieldMath.ts`).

- A grid of blocks fills the viewport; cell size grows to keep the block count under a cap (60fps guard).
- Blocks **flow in and out** on pointer proximity (quadratic falloff, low amplitude — quiet-but-alive).
- A click emits a **pulse** that ripples outward and **decays linearly to zero** in bounded time.
- A **single `requestAnimationFrame` loop**; per-block state is plain objects mutated in place, never React state.
- `data-field-state` reflects `animating` / `reduced` / `degraded` (observable contract).
- The loop **pauses on tab-hide** (`visibilitychange`) and never runs under `prefers-reduced-motion`.
- Canvas init failure degrades silently; the app still renders (edge 2).
- The canvas is `aria-hidden`, `pointer-events: none`, pinned on a dedicated `z-index` field tier behind the content.
- The field reads its colours from new `--field-*` theme-token **names** in `styles.css`; the full
  light/dark token restructure and both-theme visual check are **P2's** job (per the plan).

### Pure/impure split
`fieldMath.ts` imports nothing from React/DOM/canvas — the tested math is genuinely pure, so the unit
tests prove what they claim. `BlockField.tsx` owns the rAF loop, canvas, listeners, and lifecycle gates.

### Filename deviation (accepted)
The plan named the pure module `field/blockField.ts`, which case-collides with `field/BlockField.tsx`
on Windows' case-insensitive filesystem (TS1149). The builder used `field/fieldMath.ts`
(+ `fieldMath.test.ts`) — same responsibilities, fully wired, no dangling references, buildable.
Reviewed and accepted as a sound resolution, not a scope change.
