## 002-P6 - Discount approval: threshold hold + lead approval

Plan 002 portion **P6** (final portion), roadmap ARCHITECTURE.md section 13 item 002, DOMAIN.md section 2 rule 3 (edges 13/14). This is the portion that turns `deals.discount.approve` from *declared, never enforced* into **enforced**, closing plan 002.

### What it does
- A discount **above the tenant-wide threshold** (a single configurable percent, resolved on the tenant via `IDiscountThresholdProvider` - the granularity the user approved in open question 2) holds a `negotiation->won` move in `negotiation` with a **pending approval recorded** instead of advancing (rule 3). The state machine returns a new `DiscountApprovalRequired` verdict; the deal records the pending flag + escalated discount level and does not change stage. The agent alone cannot clear it - no path through `TransitionAsync` clears the hold.
- `POST /api/deals/{id}/approve-discount` under **`deals.discount.approve`**: a caller with the permission clears the hold (audited: who + why, via P5's host-side `IAuditTrail` seam in the composition root), after which the same over-threshold move wins; a caller without the permission is denied (**403**) before any deal is loaded. Missing reason -> 400; nothing pending -> 409; out-of-scope/empty-scope deal -> non-leaking 404; stale `xmin` -> 409.
- Threshold resolved in the **application layer** and passed into the pure state machine as an optional input - the domain never reaches for a tenant setting.

### Encoding (no migration)
Pending approval is modeled on P4's existing `pending_approval` / `pending_approval_discount_pct` columns; "approved" is `PendingApproval == false && PendingApprovalDiscountPct >= DiscountPct` (`Deal.IsDiscountApproved`). Those columns are set only by domain methods (`HoldForDiscountApproval`, `ApproveDiscount`), and the only clearing path is the `deals.discount.approve`-gated endpoint - so the encoding cannot be spoofed by a crafted request, and raising the discount after approval re-holds. **No schema change was needed.**
