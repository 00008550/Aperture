# 009-P1 — The gate, before there is anything to gate

Plan: [`docs/plans/009-raw-sql-scope-safety.md`](../009-raw-sql-scope-safety.md), portion **P1**.
Roadmap: `ARCHITECTURE.md` §13 — the raw-SQL half of 001's authorization spine, split out; sequenced
after 001 and before 002.

## What this portion does

Raw SQL bypasses EF Core's global tenant query filter, so it is the one place where fail-open is the
path of least effort. This portion builds the **negative half** of the defence — a gate that fails
the build the moment a raw-SQL entry point appears outside the sanctioned wrapper — *before* the
Dapper package lands (009-P3), so the constraint exists before the thing it constrains. No production
code is added; there are zero production raw-SQL call sites today.

- `src/Aperture.SharedKernel.Tests/Architecture/RawSqlIsScopedTests.cs` (new) — two build-failing
  assertions plus detector self-verification:
  - No production `.cs` file under `src/` names `Dapper`, `NpgsqlConnection`, `FromSqlRaw`,
    `FromSqlInterpolated` or `ExecuteSqlRaw`; offenders are reported with `path:line` (edge 12).
  - No `.csproj` outside the sanctioned project carries a Dapper `PackageReference` (edge 13).
  - The exemption is a **path rule** — `.Tests/` and `Aperture.SharedKernel/Data/` — not a magic
    comment a production file could paste to exempt itself (edge 14).
  - The regex is exercised against fixture strings (positive and negative), so a broken detector
    cannot pass identically to a genuinely clean tree.
- `scripts/measure.sh` (new `rawsql` mode) — the cheap grep that runs without a build, mirroring the
  endpoint-policy gate's grep/test pairing. Lists every raw-SQL touchpoint in `src/` with `file:line`,
  labels each as test-exempt / sanctioned / production, prints a count, and exits non-zero if any
  production call site exists.
- `.github/pull_request_template.md` — the raw-SQL checklist item now points at the gate.
- `docs/ARCHITECTURE.md` §12 — the raw-SQL/Dapper row marked `◐ gate only (009-P1)`: the negative
  half is built, the positive half (fragment builder, `ScopedConnection`) is 009-P2/P3.
